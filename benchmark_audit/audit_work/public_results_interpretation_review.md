# Independent stress review: matching and public-result interpretation

## Executable verification

`matching_validation.py` imports the unchanged `corrected()` implementation from `public_audit/run_public_audit.py`, passively records source/donor row indices at return, and compares the returned cardinality against **every permutation** for 166 tiny synthetic fixtures. It examines 924,960 permutations; all certificates pass. Cases include 130 fixtures with repeated beta identity, 136 with repeated peptide identity, and 38 with multiple HLAs. Fixtures range from one to eight rows. The supplementary JSON identifies each instance, exhaustive optimum, selected count, and witness permutation.

The mathematical contract is sound: identity assignment costs n; a forbidden edge alone costs n+1, so no optimal solution can use one. A valid off-diagonal edge costs zero, while each fixed point costs one. Minimum cost therefore maximizes the retained nonfixed rows. Nonfixed permutation cycles close on their own row set, preserving source/donor membership and all requested marginal counts. This is optimal under the **closed row-subset, within-HLA assignment** contract.

The unconstrained maximum bipartite matching size is only an upper bound. A three-node directed path has maximum bipartite size two but no nontrivial cycle, hence a closed-subset optimum of zero. In the real public cohort, HLA-B*27:05 has 130 rows, bipartite upper bound 49, and closed-subset retention 38. Do not present the upper bound as an independently sufficient optimality certificate.

## Required interpretation limits

1. **Simple shuffling is already strong on one axis.** For the complete score>=1 cohort, the original sampler with row shuffling has peptide total variation zero and peptide identity-oracle AUROC 0.5 for every observed seed at batch sizes 16, 64, and 256. The matching correction adds known-positive exclusion and within-HLA/closed-assignment guarantees; its marginal-AUROC result should not be marketed as superiority over shuffling when both are 0.5.
2. **The identity oracle is resubstitution.** The category-score result diagnoses class-conditional distribution differences in the generated dataset. It is not held-out prediction performance. The matching oracle of 0.5 follows from exact marginal equality by construction, rather than demonstrating learned-model generalization.
3. **Retention changes the target cohort.** The correction retains 2,691 of 3,182 positives (84.57%) and 22 of 41 HLA strata. Nineteen HLA strata disappear entirely. HLA frequency total variation between the original and retained positive cohorts is 0.127412. Marginal equality compares generated negatives with retained positives, not with the original population.
4. **Known-positive contradictions have a precise scope.** The reference contains eligible public-release records across evidence scores>=0. Collision counts are contradictions with this registry, not a measured biological false-negative rate. Moreover, the key is CDR3beta–peptide–HLA; alpha/V/J/full-receptor context is omitted. A beta-level record match does not establish binding for every complete alpha/beta receptor sharing that beta.
5. **Unknown does not mean negative.** Excluding registry positives still leaves potentially undiscovered binders in the decoys. A corrected sampler supplies controlled unobserved pairs, not experimentally verified nonbinders.
6. **Split before matching.** Global matching followed by CV can create fold dependence and anti-correlated marginal counts. Freeze train/test/CV partitions first and construct matching separately inside each partition for any learned-model benchmark.
7. **Generalization beyond this source remains untested.** The public audit independently applies source logic to a declared VDJdb release. It does not reconstruct the manuscript's unavailable pooled original cohort or verify its learned-model results.
8. **The optimization is scoped.** Maximum retention under closed within-HLA row assignment is not a claim of maximum retention across all weighted, duplicate-allowing, or cross-HLA distribution-balancing schemes. Dense costs have quadratic memory use and Hungarian assignment is cubic in a stratum size in the usual formulation; broad scalability is not established by the current 3,182-row application.
